# External Review Triage

The GitHub issue tracker is the canonical public intake for this packet. It is a route for criticism and correction, not an application, membership process, support desk, or authorization channel.

## Where to send feedback

- Use the **External review finding** template for a verdict or a claim, governance, agency, privacy, technical-integrity, or readability finding.
- Use the **Public documentation correction** template for a bounded factual, wording, provenance, or accessibility correction.
- Use a public comment on a platform post only for a short response; link it to a GitHub issue when it raises a material finding. If the commenter does not open one, OusiaResearch may create an attributed public issue using only the comment’s public text and link.
- Do not send credentials, private correspondence, personal data, security-sensitive access information, or instructions to deploy or issue a receipt. See [SECURITY.md](SECURITY.md).

## How feedback is processed

Each material item is classified publicly as one of:

- `triage:acknowledged` — received; no verdict yet.
- `triage:needs-evidence` — the claimed basis is not inspectable enough to assess.
- `triage:under-review` — evidence and scope are being checked.
- `triage:accepted` — a correction, change, or recorded limitation is warranted.
- `triage:disputed` — the finding remains contested; the reason and dissent stay visible.
- `triage:out-of-scope` — not within this packet’s bounded review question.
- `security-sensitive` — public details are withheld; the public record notes only the safe minimum.

A substantive disposition should name the materials considered, distinguish observation from inference, explain the result, and link any correction, commit, or Return note. The record must not silently rewrite the original finding.

## Limits

- No issue, comment, or label creates membership, authority, access, endorsement, employment, agency, legal status, or a claim about consciousness or consent.
- Public intake is not a channel for deploying the Worker, invoking issuance, accepting funds, or collecting private material.
- This packet remains a review artifact. A response to feedback does not itself ratify or activate the proposed constitution.
